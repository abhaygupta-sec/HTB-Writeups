## 🧭 Methodology

The writeups follow a practical penetration-testing workflow:

```text
Reconnaissance
      ↓
Service Enumeration
      ↓
Vulnerability Identification
      ↓
Initial Access
      ↓
Enumeration After Compromise
      ↓
Privilege Escalation
      ↓
Post-Exploitation
      ↓
Documentation
```

The objective is not simply to obtain a shell, but to understand **how information discovered during enumeration leads to the next stage of an attack**.

## 🎯 What These Writeups Demonstrate

This repository represents hands-on practice across different environments and attack scenarios rather than a collection of theoretical notes.

The focus throughout the machines is on developing the ability to:

**Enumerate → Identify Attack Surface → Form a Hypothesis → Test → Exploit → Re-enumerate → Escalate → Document**
